# Wallpapers

Pictures dropped into this folder ship inside the extension and appear in Settings, Wallpaper, "From the set". A file named after a theme (`miku-dark.webp`, `miku-light.webp`, `sakura-dark.webp`, `sakura-light.webp`) is used for that theme; otherwise the first file is used.

Keep them light: 2560 px wide WebP at quality around 82 lands near 300 KB.

```powershell
magick miku-dark.png -resize 2560x -quality 82 miku-dark.webp
```

Hatsune Miku is a Crypton Future Media character. Fan art for a free, non commercial project is fine under the Piapro Character License; credit Crypton and keep the extension free.

## Shared rules for every prompt

The new tab puts the clock at the center (Stage) or bottom left (Zen), so the left 55% of the frame stays calm. The UI draws its own diagonal "twin tail" ribbons at about 22 degrees, so the art echoes that angle instead of fighting it.
