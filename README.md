## Install

<details><summary><b>VS Code, Cursor, VSCodium</b></summary>

1. Install from Open VSX, or download the `.vsix`.
2. For the `.vsix`: Extensions → `⋯` → Install from VSIX.
3. Ctrl+K Ctrl+T and pick a Hatsune Miku look.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/vsc/README.md).

</details>
<details><summary><b>JetBrains IDEs</b></summary>

1. Settings → Plugins → `⚙` → Install Plugin from Disk, pick the `.zip` (or install from the Marketplace).
2. Settings → Appearance & Behavior → Appearance → Theme.
3. Optional wallpaper: Settings → Appearance & Behavior → Hatsune Miku.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/jetbrains/README.md).

</details>
<details><summary><b>Zed</b></summary>

1. Unpack the `.zip`.
2. Command palette → `zed: install dev extension`, pick the folder.
3. Command palette → `theme selector: toggle`.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/README.md#editors).

</details>
<details><summary><b>Neovim</b></summary>

1. Copy `colors/` into `~/.config/nvim/` (Windows: `%LOCALAPPDATA%\nvim\`).
2. `:colorscheme hatsune-miku`, or `hatsune-miku-light`, `hatsune-miku-sakura`, `hatsune-miku-sakura-light`.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/neovim/README.md).

</details>
<details><summary><b>Sublime Text</b></summary>

1. Preferences → Browse Packages, unpack into `User`.
2. Preferences → Select Color Scheme.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/sublime/README.md).

</details>
<details><summary><b>Notepad++</b></summary>

1. Unpack the `.zip`.
2. Settings → Import → Import style theme(s), pick an `.xml`.
3. Settings → Style Configurator → Select theme.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/notepadpp/README.md).

</details>
<details><summary><b>Firefox</b></summary>

1. Install from addons.mozilla.org; Firefox keeps it updated.
2. Open a new tab; the gear in the corner holds layouts, widgets and looks.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/browser/README.md).

</details>
<details><summary><b>Chrome, Edge, Helium, any Chromium</b></summary>

1. Unpack the `.zip`.
2. `chrome://extensions` → Developer mode on → Load unpacked → pick the folder.
3. Frame colors are separate extensions, one per look.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/browser/README.md).

</details>
<details><summary><b>Zen</b></summary>

1. Install Sine, then add the mod from this repository; the readme walks through it.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/browser/zen/readme.md).

</details>
<details><summary><b>Telegram for Android</b></summary>

1. Easiest: open a cloud theme link on your phone; Telegram applies it and keeps it updated.
2. Or send the `.attheme` to Saved Messages, tap the file → Apply.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/README.md#telegram).

</details>
<details><summary><b>Telegram Desktop</b></summary>

1. Easiest: open a cloud theme link in Telegram Desktop; it applies and keeps it updated.
2. Or open the `.tdesktop-theme` in Telegram (or send it to Saved Messages and click it) → Apply.

More in the [guide](https://github.com/Vadim-Khristenko/HatsuneMikuEditorTheme/blob/master/README.md#telegram).

</details>
